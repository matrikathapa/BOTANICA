# 🌿 BOTANICA — A Little Growth, One Count at a Time

BOTANICA is a botanical-themed counter application where every count contributes to the growth of a little plant.

Built using HTML, CSS and JavaScript, the application combines DOM manipulation with an interactive plant-growth experience. Watch a tiny seed gradually transform into a fully flourished plant as the counter increases.

## ✨ Features

- **Interactive Counter:** Increase and decrease the counter using simple controls.
- **10 Growth Stages:** Watch the plant progress through 10 distinct visual growth stages.
- **100-Count Growth Journey:** The plant reaches its final growth stage at 100 counts.
- **Unlimited Counting:** The counter continues working beyond 100, while the plant remains fully grown.
- **Dynamic Growth Information:** Plant descriptions, stage indicators and progress information update as the counter changes.
- **Reset Functionality:** Start a fresh growth journey whenever you like.
- **Responsive Design:** Enjoy the experience across desktop, tablet and mobile screens.
- **Botanical Aesthetic:** A warm, greenhouse-inspired interface with illustrated plant elements.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

You don't need to install any dependencies to run BOTANICA.

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

That's it! Your little garden is ready to grow.
